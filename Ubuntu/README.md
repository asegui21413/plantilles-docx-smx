# Plantilles per a Ubuntu / Linux

Aquesta carpeta conté les plantilles .docx preparades per utilitzar amb WPS Office o LibreOffice a Ubuntu/Linux.

Els fitxers .docx són els mateixos que a la carpeta Windows (format estàndard compatible amb ambdós sistemes).

## Contingut previst
- 01_Convocatoria_Reunio.docx
- 02_Curriculum_Vitae.docx
- 03_Factura.docx
- 04_Solicitud_Instancia.docx
- 05_Document_Dues_Columnes.docx
- 06_Diploma.docx
- 07_Document_Imatge_Fons.docx

Els scripts de generació estan a la carpeta `scripts/` (creats a Linux).
