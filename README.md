# Plantilles DOCX - SMX (Sistemes Microinformàtics i Xarxes)

Plantilles de documents creats amb processador de textos (compatibles amb **WPS Office**, LibreOffice Writer i Microsoft Word).

## Documents inclosos

| Fitxer | Descripció |
|--------|------------|
| `01_Convocatoria_Reunio.docx` | Convocatòria de reunió del Club Marítim de Maó |
| `02_Curriculum_Vitae.docx` | Curriculum vitae modern |
| `03_Factura.docx` | Factura d'empresa (Tecnomenorca SL) |
| `04_Solicitud_Instancia.docx` | Sol·licitud / Instància per a concurs-oposició |
| `05_Document_Dues_Columnes.docx` | Document estil diari comarcal amb **dues columnes** |
| `06_Diploma.docx` | Diploma de millor alumne de 1r de SMX (horitzontal) |
| `07_Document_Imatge_Fons.docx` | Document amb imatge de fons (Unsplash) |

## Estils i característiques aplicades

- **Tipografies**: Georgia, Calibri, Arial, Times New Roman
- **Colors**: blau marí (#1A5276), accents daurats i vermells
- **Capçaleres i peus de pàgina** amb numeració de pàgina
- **Marges** personalitzats
- **Taules** professionals amb bordes
- **Columnes** (document 5)
- **Orientació horitzontal** (diploma)
- **Imatge de fons** descarregada d'Unsplash respectant la llicència lliure

## Objectius assolits

- Utilització de processadors de text i característiques avançades
- Disseny de plantilles de diferents tipus
- Introducció d'imatges respectant drets d'autor
