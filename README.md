# Plantilles DOCX - SMX

Plantilles de documents creats amb processador de textos (compatible amb WPS Office, LibreOffice, Microsoft Word).

## Contingut

1. **01_Convocatoria_Reunio.docx** - Convocatòria de reunió del Club Marítim de Maó
2. **02_Curriculum_Vitae.docx** - Curriculum vitae modern
3. **03_Factura.docx** - Factura d'empresa (Tecnomenorca SL)
4. **04_Solicitud_Instancia.docx** - Sol·licitud / Instància per a concurs-oposició
5. **05_Document_Dues_Columnes.docx** - Document estil diari comarcal amb dues columnes
6. **06_Diploma.docx** - Diploma de millor alumne de 1r de SMX (orientació horitzontal)
7. **07_Document_Imatge_Fons.docx** - Document amb imatge de fons (Unsplash, llicència lliure)

## Estils aplicats

- Tipografies: Georgia, Calibri, Arial, Times New Roman
- Colors corporatius (blaus marins, accents)
- Capçaleres i peus de pàgina amb numeració
- Marges personalitzats
- Taules, columnes, bordes decoratives
- Imatge de fons respectant drets d'autor (Unsplash)

## Generació

Els documents s'han generat amb la biblioteca `docx` de Node.js. Els scripts de creació estan inclosos.
