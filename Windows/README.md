# Plantilles per a Windows

Aquesta carpeta conté les plantilles .docx preparades per utilitzar amb Microsoft Word o WPS Office a Windows.

Els fitxers .docx són els mateixos que a la carpeta Ubuntu (format estàndard compatible amb ambdós sistemes).

## Contingut previst
- 01_Convocatoria_Reunio.docx
- 02_Curriculum_Vitae.docx
- 03_Factura.docx
- 04_Solicitud_Instancia.docx
- 05_Document_Dues_Columnes.docx
- 06_Diploma.docx
- 07_Document_Imatge_Fons.docx

Pots descarregar els documents des de la conversa o generar-los amb els scripts de la carpeta `scripts/`.
